# Career Compass

All instructions for working on this repo are in [AGENTS.md](AGENTS.md). Read it first.

Short version: edit the source files listed in AGENTS.md (never `worker.js` or `index.html`,
which are generated), run `npm ci && node cf/build.mjs` to check the build, and push to `main`
to deploy to Cloudflare Pages.

The older notes that used to be here described the previous ChatGPT Sites hosting and the old
`src/` folder; they no longer apply to this Cloudflare deployment.
